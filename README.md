# ✨ Random Quote Generator (Python)

## 📌 Introduction
The **Random Quote Generator** is a simple Python application that displays a **motivational quote** each time the user presses Enter.  
It is designed as a beginner-friendly project to demonstrate **random selection, lists, loops, and user interaction** in Python.

Motivational quote generators are commonly used in:
- Productivity apps  
- Learning platforms  
- Wellness tools  
- Daily inspiration widgets  

This project helps beginners understand how **real-world mini tools** are built using basic programming concepts.

---

## 🎯 Project Objectives

The main goals of this project are:

- To learn how to use the **random module** in Python  
- To store and manage data using **lists**  
- To practice **loops and user input handling**  
- To create a **simple interactive command-line tool**  
- To build a **clean beginner GitHub portfolio project**

---

## ✨ Features

### 🎲 Random Quote Selection
Each time the user presses Enter, the program:
- Selects a **random quote** from the list  
- Displays it instantly in the terminal  

### 🔁 Continuous Interaction
- Users can generate **unlimited quotes**
- Program runs until the user types **exit**

### 🧠 Beginner-Friendly Code
- Clean structure  
- Easy-to-read logic  
- Perfect for Python beginners  

---

## 🛠 Technologies Used

- **Python 3**
- **random module**
- **Lists & loops**
- **Standard input/output**

No external libraries are required.
